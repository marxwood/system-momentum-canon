# System Momentum Canon — Core

Canonical navigation is defined **exclusively** in: `./INDEX.md`.

This document is an orientation surface for humans.
It must not be treated as a canonical entrypoint or a source of canonical order.

Core is split into two layers:

- **Constitution**: civilizational foundations, axioms, definitions, constraints.
- **Authority**: semantic authority, regimes, validity and interpretation discipline.

Core also defines foundational constructs:

- **Mindframe**: the unique canonical derivative and canonical runtime model (conceptual).
- **State**: the time-indexed, attributable condition of a system.
- **Projections**: non-authoritative representations derived from State.
- **Surfaces**: authority-neutral boundaries of capability exposure.
- **Intent**: the semantic precondition for institutional agency.
